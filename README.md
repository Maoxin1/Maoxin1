# 你好，我是 mantou👋

我把真实问题转化成可验证的小工具、AI 工作流和公开案例。这里展示已经交付的作品、已知限制与后续复盘，不把进行中的实验包装成成熟产品。

## 目前关注

- **可复用 AI 工作流**：把提示词优化、推理检查、研究方法沉淀为可验证的 Codex Agents；
- **本地优先的小工具**：让阅读、行动记录与训练等个人流程更容易执行；
- **公开可核查的案例**：解释真实问题、失败、测试结果和限制，而不只展示完成的界面。
