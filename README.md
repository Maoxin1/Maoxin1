# 你好，我是馒头（Maoxin1）👋

我在整理一套可长期维护的 AI 工具、知识文档与个人工作流，也持续记录写作、学习和实践过程。

## 目前关注

- 把 AI Agent 与提示词方法沉淀为可验证、可复用的工具；
- 用清晰的心智模型理解命令行、Git 和 AI 编程工具；
- 建设重视隐私、来源和长期可维护性的个人知识系统；
- 通过博客记录成长、生活与作品。
